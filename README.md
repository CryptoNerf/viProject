# viProject

Интерактивное web-приложение для создания органической графики жестами рук, голосом, мышью и касаниями через веб-камеру.

Демо: <https://vi-project.vercel.app>

## Описание

На холсте создаются «молекулы» — мягкие формы, которые плавно сливаются друг с другом при сближении (алгоритм метаболов, контуры строятся через marching squares). Молекулами можно управлять жестами перед камерой, мышью, с клавиатуры или пальцами на сенсорном экране, а в режиме редактора — раскрашивать и дорисовывать карандашом.

## Возможности

### Жесты (камера)

Все удерживаемые жесты срабатывают через **1 секунду** — над рукой виден круговой индикатор прогресса.

| Жест | Действие |
| ---- | -------- |
| Щипок большим + указательным | создать круг |
| Щипок большим + средним | создать треугольник |
| Щипок большим + безымянным | создать сердце |
| Щипок большим + мизинцем | создать звезду |
| Открытая ладонь рядом с молекулой | захватить и перемещать |
| Открыть рот | войти/выйти из режима редактирования (✎) молекулы под ладонью |
| Все кончики пальцев вместе над молекулой | зафиксировать молекулу |
| Все пальцы вместе на обеих руках | зафиксировать все молекулы |
| Только мизинец рядом с молекулой | разблокировать |
| Скрещённые указательный и средний | удалить молекулу |
| Голос / звук | контуры молекул вибрируют |

В режиме редактирования (✎):

- **одна открытая ладонь** — перемещение, ширина ладони задаёт размер;
- **две открытые ладони** — растяжение и поворот вдоль линии между руками.

### Мышь и клавиатура

Панель инструментов слева: **Select**, **Create**, **Delete**, а также **Lock/Unlock** для выбранной молекулы.

- Перетаскивание — перемещение выбранной молекулы
- `Ctrl`/`Cmd` + перетаскивание вверх/вниз или колесо мыши — размер
- `Shift` + перетаскивание — растяжение
- `Alt` + перетаскивание влево/вправо — поворот
- `Ctrl/Cmd + Z` — отменить, `Ctrl/Cmd + Shift + Z` или `Ctrl + Y` — повторить
- `Ctrl/Cmd + C` / `Ctrl/Cmd + V` — копировать / вставить молекулу под курсор
- `Delete` / `Backspace` — удалить выбранную молекулу, `Esc` — снять выделение

### Телефон и планшет

Интерфейс сам подстраивается под устройство:

- **Телефон** — панель инструментов внизу экрана, настройки и палитра выезжают снизу (в горизонтальной ориентации — справа), учтены вырез экрана и полоска «домой».
- **Планшет** — крупная боковая панель инструментов, настройки и палитра — боковые панели справа.
- **Касания:** тап по пустому месту — создать молекулу (инструмент Select или Create), перетаскивание — перемещение, двумя пальцами — масштаб и поворот, долгое нажатие — удаление; инструмент Delete удаляет касанием. Кнопки Undo/Redo и переключение режима — на панели инструментов.
- **Apple Pencil / стилус** в режиме редактора всегда рисует (если не выбраны ластик или заливка), толщина линии зависит от силы нажатия; касания ладонью во время рисования игнорируются.
- На мобильных распознавание жестов работает в экономном режиме (~20 кадров в секунду), чтобы меньше грелся телефон.

### Режим редактора (кнопка «Editor mode»)

- **Заливка** молекулы (внутренность, контур или оба) и замкнутых областей, нарисованных карандашом
- **Карандаш** и **ластик** (обычный — стирает частями, умный — удаляет штрих или заливку целиком)
- Эффекты: **тиснение** (emboss) и **микро-полоски** с градиентом
- Фон холста: цвет, картинка или видео из файла

### Экспорт

- **PNG** — с фоном или с прозрачным фоном
- **Видео** до 30 секунд (WebM, в Safari — MP4). Элементы интерфейса (курсоры рук, рамки выделения) в файл не попадают

### Параметры

- Размер новых молекул (30–300, по умолчанию зависит от ширины экрана)
- Сила слияния (0.5–3.0)
- Звуковая чувствительность (5–50)
- Звук влияет на форму / показ видео с камеры

## Технологии

- **MediaPipe Hands** — распознавание рук и жестов
- **MediaPipe FaceMesh** — распознавание открытого рта
- **Web Audio API** — анализ звука с микрофона
- **Canvas 2D** — рендеринг, **marching squares** + SDF-формы — плавные контуры метаболов
- **MediaRecorder** — запись видео
- **StPageFlip** — книга-мануал (`manual.html`)

Файлы моделей MediaPipe лежат локально в `public/mediapipe/` (см. [MEDIAPIPE-SETUP.md](MEDIAPIPE-SETUP.md)).

## Запуск локально

Камера и WebAssembly требуют HTTP-сервера (`https://` или `localhost`) — открыть `index.html` двойным кликом (`file://`) не получится.

```bash
git clone https://github.com/CryptoNerf/viProject.git
cd viProject
python3 -m http.server 8000 -d public
```

Откройте <http://localhost:8000> (рекомендуется Chrome/Edge) и разрешите доступ к камере и микрофону. Без камеры приложение работает в режиме мыши/касаний, без микрофона — без звуковых эффектов.

## Деплой

Проект развёрнут на Vercel: корнем сайта служит папка `public/` (см. `vercel.json`). Сборка не требуется.

## Структура

```text
public/
├── index.html            # Приложение (разметка, стили и логика)
├── manual.html           # Книга-мануал по жестам (js/manual-flip.js, css/manual.css)
├── service-worker.js     # Офлайн-кеш (PWA)
├── manifest.json         # PWA-манифест
├── mediapipe/            # Локальные WASM и модели MediaPipe (~25 МБ)
├── icons/, img/, fonts/  # Иконки, иллюстрации мануала, шрифт
download-mediapipe.sh     # Обновление файлов MediaPipe
```

## Требования

- Современный браузер (Chrome, Edge, Safari, Firefox)
- Веб-камера (фронтальная на мобильных устройствах), микрофон — опционально
- Работает на компьютерах, планшетах и смартфонах
